# 策略与流程

## 用户看到的流程

```text
选择电子书
→ 格式预检
→ 展示可否转换、输出格式和预计模型用量
→ 用户确认
→ 本地过滤并抽取候选片段
→ 模型只处理候选片段
→ 生成新的学习版 EPUB
→ 导入微信读书阅读
```

阅读阶段不需要插件、网络或实时翻译。一次性转换阶段可以调用用户配置的模型；只有经过本地过滤的候选文本会被发送给模型。

## Codex 直接上传时的落地方式

用户只需上传电子书并提出转换要求。Codex 调用本 Skill 中唯一的脚本入口 `scripts/convert_book.py`：先使用 `--dry-run` 生成候选清单，再基于该清单生成 `selections.json`，最后通过 `--selections` 写出 EPUB。用户无需自己拆书、运行命令或处理 EPUB 内部文件。

脚本也支持用户配置的 OpenAI 兼容模型 API；这不是默认前提。无论由 Codex 还是外部模型做选择，都只处理本地已经筛出的候选段落，不能将整书发送给模型。

## 格式决策

| 输入 | 决策 | 输出 |
| --- | --- | --- |
| EPUB | 直接处理章节 XHTML | 学习版 EPUB |
| TXT | 识别章节/段落后生成可重排 EPUB | 学习版 EPUB |
| MOBI/AZW/AZW3（无 DRM） | 先转换为 EPUB，再按 EPUB 处理 | 学习版 EPUB |
| MOBI/AZW/AZW3（有 DRM 或无法读取） | 停止，不规避保护 | 无 |
| PDF（任何类型） | 立即提示不支持 | 无 |

文件扩展名只用于初步提示；实际检查容器结构、加密状态和是否可以提取正文。不能可靠判断时应停止，而不是生成可能损坏的书。

## 低密度策略

网页扩展的“当前页面覆盖率”不适用于连续阅读。默认读感目标是：**约翻两页，遇到一处英文提示**。电子书按整书预算控制，并在章节间平摊：

| 模式 | 建议上限 | 适用 |
| --- | --- | --- |
| 轻度（默认） | 约每 2 个阅读页 1 处；初始估算为每 400–600 个中文字最多 1 处 | 连续沉浸阅读 |
| 标准 | 约每 1 个阅读页 1 处；初始估算为每 250–350 个中文字最多 1 处 | 明确希望更频繁练习 |
| 偏高 | 约每半页 1 处；初始估算为每 150–220 个中文字最多 1 处 | 短书或复习；不建议默认 |

“页”会随微信读书的字体、字号、边距和设备屏幕变化，脚本无法精确预知。因此字数仅是生成前的估算，首次产物必须在目标阅读器中抽查：若实际读感偏密或偏疏，再调整每页参考字数。所有数值都是上限，不是必须填满的目标。始终额外执行：每句至多一处；候选之间保留明显距离；不为凑配额选择低价值内容。

## 本地优先过滤

模型不负责浏览全书。脚本应先将书拆成章节和段落，并在本地完成：

1. 删除不适合正文学习的结构和文本。
2. 按字数为章节分配最大预算。
3. 过滤无效段落，按章节均匀抽样，且满足最小间隔。
4. 默认只保留最终预算约 2 倍的候选段落；仅在模型经常返回空、且用户接受更多 token 消耗时才提高到 3–4 倍。候选可附带相邻一句上下文，但模型只能替换目标段落内的文字。
5. 按批请求模型。轻度模式每个候选段落最多返回一处；模型返回空是正常结果。

候选数量必须同时受整书预算、单章预算和用户设置的最大模型输入量约束。转换前报告“预计替换数”和“预计发送的候选段落数”，不要伪装成精确承诺。

## 模型输出与写回

模型是“候选片段选择器”，不是全文翻译器。每项输出至少包含：

```json
{
  "chunkId": "chapter-03-p-17",
  "quote": "高速增长期",
  "start": 12,
  "end": 17,
  "en": "a period of rapid growth",
  "type": "phrase"
}
```

脚本验证 `quote` 与 `start/end` 完全一致、位置没有重叠、内容符合规则后，才将范围替换为：

```html
<span class="english-immersion-mark">a period of rapid growth(高速增长期)</span>
```

使用下列样式，且只影响新插入的标记：

```css
.english-immersion-mark {
  color: inherit;
  text-decoration-line: underline;
  text-decoration-color: #38bdb4;
  text-decoration-thickness: 2px;
  text-underline-offset: 4px;
  text-decoration-skip-ink: none;
}
```

不得按 `quote` 的首次文本匹配来写回。相同短语可能在同一段或章节中重复，必须按已验证的字符偏移或 DOM 范围处理。

## 可靠性与产物

- 每一批模型结果以“来源文件哈希 + 设置 + 段落 ID”缓存；同一输入重跑不重复花费 token。
- 在批次之间保存 checkpoint，可断点续跑。
- 保留原 EPUB 中未修改的资源；输出新的文件名，例如 `原书名-英语学习版.epub`。
- 最终报告包括：格式检查结果、总中文字数、设定预算、候选段落数、实际替换数、模型调用/跳过数和未处理章节。
