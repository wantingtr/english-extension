# 电子书英语沉浸转换

为个人学习生成一本新的 EPUB。阅读体验必须以中文为主：只将精选、可迁移的中文表达替换为自然的 `English(原中文)`，并为整个替换内容加青绿色下划线。

## 范围与安全边界

- 接受 EPUB 和 TXT。MOBI、AZW、AZW3 仅在确认可读取且没有 DRM 后接受，并先转换为 EPUB 再处理。
- 遇到任意 PDF 都在读取内容前拒绝。说明此流程暂不支持 PDF；不要进行 OCR、提取或修改。
- 来源文件加密、受 DRM 保护、损坏或无法可靠读取时，停止并说明无法转换。绝不移除或绕过 DRM。
- 不改动原文件。始终生成新的 EPUB，并在其旁边或用户指定的输出目录中写入简短转换报告。
- 使用远程模型时，首次请求前说明：只会向用户配置的模型服务商发送经过本地过滤的候选文本；默认不发送整本书。

## 工作流

1. 根据文件实际结构而非扩展名校验文件。在任何模型请求前，报告来源类型、转换路径、输出格式与阻塞原因。
2. 将接受的输入规范化为章节和段落文本。尽可能保留 EPUB 元数据、目录、封面、图片和原有样式。
3. 根据所选密度计算整书替换预算。预算是最大值，而非必须填满的配额。
4. 任何模型调用前，先执行确定性的本地过滤和按章节感知的抽样。只提交少量、均匀分布的候选文本，并保留足够的句子上下文以自然翻译所选表达。
5. 要求模型返回严格的结构化候选。每项必须包含精确原文引用、自然英文以及 word/phrase/sentence 类型。优先可迁移的单词与短语；不要翻译整段。
6. 校验精确偏移，剔除重叠候选，执行章节与间隔上限；只将通过校验的源文本范围替换为 `English(原中文)`。
7. 为每个替换项添加青绿色下划线 class，打包为有效 EPUB，并报告实际替换数、发送给模型的候选文本、跳过内容及失败情况。

在定义转换方案、提示词或实现前，先阅读 [references/strategy.md](references/strategy.md)。

## 用户上传电子书时的执行方式

本 Skill 的唯一可执行入口是 [scripts/convert_book.py](scripts/convert_book.py)。用户上传电子书并要求转换时：

1. 先运行 `python3 scripts/convert_book.py <输入路径> --output <输出路径> --dry-run`。它不会调用模型或修改书，只生成候选清单和预检报告。
2. 向用户报告格式判断、预计替换预算、候选段落数量和 PDF/DRM 等阻塞原因。PDF 或无法读取的受保护文件必须在此停止。
3. 处理候选清单，而不是全文。生成严格的 `selections.json`，每项包含 `paragraphId`、`quote`、`start`、`end`、`en` 与 `type`；同一段至多一项。可由 Codex 完成选择，也可在用户授权发送候选文本后让脚本调用其配置的兼容模型 API。
4. 使用 `python3 scripts/convert_book.py <输入路径> --output <输出路径> --selections selections.json` 写出最终 EPUB。若使用远程 API，改为传入 `--api-key` 或设置 `DEEPSEEK_API_KEY`，且再次确认只会发送候选文本。
5. 检查最终报告和 EPUB ZIP 结构后，再把输出文件路径交给用户。

不要要求用户手动运行这些命令；用户上传文件后由 Codex 执行。没有电子书文件时，不要假装已完成转换。

## 转换规则

- 默认使用**轻度**密度。绝不沿用浏览器扩展面向单页的覆盖率抽样策略作为整书策略。
- 面向用户将默认读感表述为：**约每两页阅读页出现一处替换**。页字数取决于设备、字体和边距，初始实现可按每 400–600 个中文字最多一处估算，且每句话最多一处。必须先用导入到目标阅读器的样书校准该估算，不能将其视为固定值。
- 让替换项跨段落保持间隔，并按章节长度分布。不要在开头章节堆积多个标记，也不要强制每章至少有一个。
- 在本地排除标题、目录、版权页、注释/参考资料、代码、URL、以数字为主的文本、过短文本、图片说明、重复模板文本及中文正文比例过低的内容。
- 模型不得选择姓名、书名、日期、价格、ID、URL、代码或仅适用于当前页面的事实。候选文本没有合适表达时，可返回空。
- 必须精确保留标点和周围中文。使用来源偏移而非“字符串首次匹配”写回，因为同一短语可能在章节内重复。

## 实现边界

此 Skill 负责描述和约束工作流；转换脚本负责归档读写、格式检查、抽样、基于偏移的编辑和打包。缓存与断点续跑可在后续根据真实大书转换的需要补充。不得在没有最终 EPUB 和报告证据时声称书已转换。
